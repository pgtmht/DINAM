# PGTMHT
**Pretty Good Theory for Mostly Harmless Things**

PGTMHT is a framework which aims to span multiple disciplines, derived from first principles.

## PGTMHT Phases:

* Phase 0 - **DINAM** / Differentiation-Driven Informational Nu-Alpha Model
    a system-agnostic microkernel for ontology and epistemology
* Phase 1 - **SPEM** / Scarcity-Preserving Ethics Microkernel
    a microkernel for ethics from universal first principles
* Phase 2 - **RSDEEM** / Recursive Supply-Demand-Equilibrium Enforcement Model
    scale-agnostic extension of DINAM & SPEM to evolutionary systems, incl. consciousness and socioeconomics
* Phase 3 - **CYM** / C6-Y6 Model
    a more intuitive interpretation and mathematical model of QFT/QM/GR
